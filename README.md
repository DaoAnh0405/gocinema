# GoCinema

## KHÔNG PUSH VÀO MAIN

### npm
- `npm run dev` | Chạy app với nodemon |
- `npm run db:up` / `db:down` | Bật / tắt MySQL |
- `npm run db:reset` | Xóa sạch DB và nạp lại `schema.sql` + `src/database/seed.sql` |
- `npm test` | Chạy test (Jest + Supertest) |

### Commit 
- chore: cấu hình
- feat: thêm tính năng
- fix: sửa lỗi
- docs: tài liệu
